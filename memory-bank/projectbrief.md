# Project Brief: Debate Tournament Management System

## Core Goal

To develop a comprehensive web application for managing debate tournaments efficiently. This includes features for tournament setup, participant registration, scheduling, bracket management, real-time updates, judging, feedback, and results display.

## Key Requirements

*   **Tournament Creation & Setup:** Allow organizers to create new tournaments, define formats (e.g., APF, BP), set rules, and configure registration details.
*   **Participant Management:** Handle registration for debaters, judges, and potentially observers. Manage teams and individual entrants.
*   **Scheduling & Pairing:** Automate or facilitate the creation of debate schedules and pairings based on tournament rules and participant availability.
*   **Bracket Management:** Visualize and manage tournament progression through brackets.
*   **Real-time Updates:** Provide live updates on schedules, pairings, results, and announcements.
*   **Judging & Feedback:** Support online ballot submission, judge assignment, and feedback collection (judge-to-debater, debater-to-judge).
*   **Results & Standings:** Calculate and display tournament results and participant standings accurately.
*   **User Roles & Permissions:** Implement distinct roles (Organizer, Judge, Debater, Spectator) with appropriate permissions.
*   **Internationalization (i18n):** Support multiple languages (English, Kazakh, Russian detected).
*   **(Potential) AI Integration:** Explore features like Automatic Speech Recognition (ASR) for transcripts.

## Scope

The system should cover the full lifecycle of a debate tournament, from initial setup to final results announcement. It aims to streamline operations for organizers and provide a seamless experience for participants.
